# 税务待办事项

适用于浙江省的本地税费申报待办工具，Windows 64 位便携版。

## 2.0 更新说明

- 全新蓝白界面，统一字体、图标、按钮及各类设置窗口。
- 重新整理企业管理与征期详情，信息展示更清晰，操作更集中。
- 优化界面空间分配，小窗口下也能方便查看和处理待办。
- 完善更新校验与安装流程，支持更新器同步升级。

## 使用与升级

解压后运行 tax_todo.exe，无需另行安装 Python。升级前关闭软件并备份 data 文件夹，再替换主程序、更新器和使用说明；保留原有 data，不要覆盖或删除。

本仓库只用于更新分发，不包含软件源码、企业信息、数据库或任何用户数据。历史版本保留在发行版页面。
